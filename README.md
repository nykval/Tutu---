# Tutu — приложение для подборок отелей

Внутренний инструмент для создания и ведения тематических подборок отелей. В приложении можно:

- выбрать географию и от одной до трёх тем;
- задать количество отелей и выгоду;
- найти уже существующую подборку или создать новую;
- автоматически подобрать отели через Tutu MCP либо добавить ссылки вручную;
- вести справочники географий и тем;
- запретить несовместимые сочетания географий и тем;
- просматривать, редактировать и удалять сохранённые подборки.

## Быстрый запуск

### Обычная работа

Откройте `index.html` двойным кликом. Текущая конфигурация подключает приложение к общему Cloudflare Worker, поэтому справочники и подборки будут общими для всех пользователей приложения.

Адрес общего сервера задаётся в [`assets/js/config.js`](assets/js/config.js).

### Запуск через локальный сервер

Дважды нажмите `Запустить подборки.command`. Откроется адрес `http://127.0.0.1:8765`.

Пока в `config.js` указан адрес Cloudflare, даже локально открытая страница использует общую базу. Чтобы полностью перейти на локальный режим, временно задайте:

```js
apiBaseUrl: ''
```

В этом режиме данные сохраняются в `data/collections.sqlite3`, а API обслуживает `local_server/server.py`.

## Как всё связано

```text
Браузер
  └─ index.html + assets/
       ├─ справочники и подборки → Cloudflare Worker
       │                            └─ Cloudflare D1 (общая база)
       └─ автоматический поиск → Cloudflare Worker
                                    └─ Tutu MCP → реальные отели
```

Текущая рабочая конфигурация:

| Компонент | Значение |
|---|---|
| Фронтенд | статические файлы из этого репозитория |
| Общий API | `tutu-collections-api.skorokirzhaboy.workers.dev` |
| Общая база | Cloudflare D1 `tutu-collections` |
| Привязка базы в Worker | `DB` |
| Поиск отелей | `https://mcp.tutu.ru/mcp` |
| Локальная база | `data/collections.sqlite3` |

Подробная схема: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Режимы работы

| Режим | Когда используется | Где хранятся данные | Автопоиск |
|---|---|---|---|
| Общий | В `config.js` указан `apiBaseUrl` | Cloudflare D1 | Да |
| Локальный сервер | `apiBaseUrl` пустой, страница открыта через `Запустить подборки.command` | SQLite | Да, при наличии доступа к Tutu MCP |
| Автономный | `apiBaseUrl` пустой, открыт сам `index.html` | `localStorage` браузера | Нет |

## База данных простыми словами

В общей базе есть три смысловые сущности:

1. `catalog_items` — изменения и дополнения справочников географий и тем, включая блокировки.
2. `collections` — параметры подборок: география, темы, количество отелей и выгода.
3. `hotel_links` — отдельные ссылки на отели внутри каждой подборки.

Основной каталог поставляется вместе с фронтендом из `catalog-data.js`. Этот файл автоматически создаётся из `data/catalog-seed.json` командой `python3 scripts/sync_catalog.py`. D1 хранит добавленные и изменённые элементы поверх него. Поэтому пустой `catalog_items` не означает, что в интерфейсе нет справочника.

Полное описание: [`docs/DATABASE.md`](docs/DATABASE.md).

## Серверная интеграция

Фронтенд никогда не обращается к D1 или Tutu MCP напрямую. Все запросы идут через Cloudflare Worker:

- Worker проверяет входные данные и несовместимые сочетания;
- читает и записывает подборки в D1;
- для автоматического наполнения вызывает `search_hotels` в Tutu MCP;
- отбирает уникальные предложения и возвращает ссылки фронтенду.

Основные API-методы перечислены в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md#api).

## Важное о production-базе

Колонки блокировок были добавлены в D1 вручную через Cloudflare Console:

- `blocked_geography_ids`;
- `blocked_theme_ids`.

Файл `cloudflare-worker/migrations/0002_catalog_blocks.sql` поэтому **физически уже применён, но не записан Cloudflare как выполненная миграция**. Не запускайте все миграции вслепую: повторный `ALTER TABLE` завершится ошибкой.

Перед любым изменением общей базы откройте [`docs/OPERATIONS.md`](docs/OPERATIONS.md).

## Проверки

После изменений в JavaScript:

```bash
node --check assets/js/app.js
node --check assets/js/icons.js
node --check cloudflare-worker/src/index.js
```

Тесты локального сервера:

```bash
python3 -m unittest local_server.test_server
```

Визуальную проверку интерфейса выполняйте отдельно в браузере.

## Ограничения текущей версии

- CORS ограничивает браузерные источники, но не является полноценной авторизацией. В общей базе не следует хранить персональные или секретные данные.
- Браузерная версия каталога генерируется из JSON; после изменения seed необходимо запустить `scripts/sync_catalog.py`.
- Для подборки сохраняются дата создания и дата последнего изменения. Полного журнала всех версий пока нет.
- История миграции блокировок в production отличается от локальных файлов, потому что изменение было выполнено через Cloudflare Console.
